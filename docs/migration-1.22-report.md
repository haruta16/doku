# Meowdoku 1.22 移植记录

状态：1.22 内容已移植并应用到当前框架；全部 12 组隔离验收通过，原始证据与逐项处置清单已归档。

## 基线与方法

产品语义基线是 `2af1f49bdde26131f85a453a821fce7351cf4885`，框架基线是 `d89f94d1dd03d1b3369054351ee95ccc93d9cb93`，共同祖先是 `7af200ca1b582a86c92ab3d498c6af43a20d201a`。本次在 `migration/meowdoku-1.22-framework` 分支工作。先保留开始时的工作区文件指纹和已有文档修改，再在独立副本中三方对比、实现、运行测试，最后核对漂移并应用。应用时原有 2,299 个文件和本次早期新增的 3 个文件均无漂移；5,510 个目标文件逐个核对一致，5,344 个测试输入与最终验收完全相同。应用时的文件清单见 [应用记录](migration/evidence/closeout/doku122-application-manifest.json)；之后只更新收尾文档和证据索引。提交前审查确认暂存内容、工作区和验证副本一致，无冲突标记；仅保留原翻译空格、Godot 导入格式及原始差异证据中的 73 处空白提示，未改写原证据来消除提示。

这不是直接 cherry-pick：两个分支从共同祖先演进，1.22 的产品代码仍在旧目录，并包含新的状态、副作用和资源路径。逐文件自动分类只负责确定冲突范围；选题、保存、奖励、结算与页面生命周期按行为重新接入。资源转换同时核对 `.tscn`、UID、动画轨道、导入设置、代码中的路径和翻译内嵌的图片路径。

原包覆盖口径为 **853 份恢复脚本、187 个场景、75 份原始翻译、59 个运行时题库文件**。题库含 65,915 条顶层记录和 45,133 份答案条目，两者都不能直接称为可玩关卡数量。原始恢复同一性证据保留原含义；主动修改后的框架实现另做行为与指纹验证，不冒称字节码等同。

完整任务清单见 [迁移计划](migration-1.22-plan.md)。文件处置与方法替代关系见 [完整覆盖审计](migration/1.22-coverage.md) 和 [逐项清单](migration/1.22-coverage.json)。全套运行证据见 [最终验收报告](validation/migration-1.22-full/report.json) 与 [验收汇总](validation/migration-1.22-full/summary.json)。

## 旧接口为什么有的消失

- `SaveStore.capture_file_snapshot/restore_file_snapshot` 的单文件回滚已退役。候选失败直接丢弃，由核心 revision 与文件事务维护一致性，不能绕开它们恢复原始文件。
- 旧 `LevelSelector` 的备份／恢复／收尾私有方法由纯候选准备和提交替代。新增策略本身完整保留，方法重命名不等于删去策略行为。
- UIManager 的窗口缓存、堆栈、遮罩与加载方法由 `UIWindowManager` 继承；逐文件方法审计必须把继承也算入，不能误报为缺失。
- 旧公共窗口中直接依赖产品的按钮保护改由产品场景准备端口注入；运行时新增控件使用同一入口。
- UIPopupQueue 的单个 `_run` 协程被事件驱动窗口交接与 Callable 任务组合替代，保留优先级、插队、取消和队列排空通知。
- 旧 `DailyAutoMarkPopup`、`RateUsPage` 场景已被上游移除，因此删除其孤儿脚本。新版评分使用 `RateUsPageV2`；每日自动标记的旧数据事务接口仅作为兼容保留。
- 调试快速跳关与模拟器保留 1.22 原用途，选题计划与成功／失败进度在一次候选事务中提交；旧 live 私有结算实现由 `MeowdokuProgressState` 接管。写失败中止当前批次，同计划回执防止重复推进。
- 旧 `game_auto_mark` 实验及其动画中断恢复器随 1.22 退出页面合同。当前恢复保存的盘面；新补叉与道具先整体提交结果再播放表现，不重新启用旧实验。
- 撤销纯 API 和旧档库存保留兼容用途，当前 1.22 底部操作界面按原版展示定位、提示、鼠标和草稿，不复活已退役的撤销按钮。

## 移植过程中发现并修复的问题

1. **候选泄漏与提前消费**：日切、选题资格和部分模块状态原先会在读取／准备阶段改活数据。现在先修改副本，真正完成业务提交后再发布。
2. **浮点存档误判**：ConfigFile 解析后重新编码可能改变浮点末位。文件验证改为比较解密后的原始编码文本，同时保留解析与结构校验，不用容差放过内容变化。
3. **重复或迟到奖励**：广告回奖、关闭、错误及弹窗复用都绑定相应身份；旧广告不能领取或关闭新奖励。
4. **页面重入**：不仅在 `await` 后检查，还检查 BGM 等同步写盘触发的通知回调；旧 `on_show` 不得在重开后认领新一代页面状态。
5. **终局半提交**：补叉分数不再在到账动画里追加；保存失败不会先改变分数、标记、奖励或关卡进度。
6. **题库可选尺寸**：SP/LK 的预览、前后翻页和胜利继续使用实际题面尺寸，避免原 9／8 常量把新版或远端题送入错误棋盘；JSON 数值转换也在入口明确处理。
7. **关闭与动画收尾**：取消后停止旧计时与等待，清临时输入锁、声音作用域和遮罩所有权；仍在动画中的对象不作为另一个权威状态源。
8. **资源路径遗漏**：不只扫描明文场景，还处理二进制翻译内的 `[img]` 路径；缺失的 GenericPopup Overlay 节点逐场景修复，不通过屏蔽警告隐藏错误。
9. **公共层反向依赖**：ScrollDragHelper 去除产品 UIManager 依赖；纯业务端口改为注入 selection stager，不通过复制整个 Autoload 树假装独立。
10. **开发功能泄漏**：GameState 调试标志、作弊命令和棋盘调试层恢复 `OS.is_debug_build()` 硬边界，运行时开关不能把 release 构建变成调试构建。
11. **恢复后的旧缓存回调**：已完成残局恢复会立即换关，旧 R4 提示缓存的延迟回调必须核对代次，不能用新尺寸读取上一局棋盘；跨日回流的重选规则也不得丢弃已经完成、尚待结算的胜利。
12. **旧测试假通过**：退役字段／节点导致的 SCRIPT ERROR 即使没有增加失败计数，也使门禁失败。既有退出泄漏台账不再豁免当前实现；旧测试按新版合同更新，新增失败和重入断言保留。
13. **检查点恢复链**：保存失败最多安排 3 次自动重试，间隔为 1、2、3 秒；连续失败后停止自动调度。关闭页面前仍 flush 最后一帧，写入结果与页面代次分别核对。恢复使用保存时冻结的残局开关；已完成档先恢复、幂等结算再直接换关，包含跨 10 天仍不能将已完成胜利当普通回流旧局重选的场景。专项 30 项通过，关闭 flush 不等于承诺每次写盘必然成功。
14. **诊断入口断链**：`fastjump` 和 Playtest 模拟器仍调用旧 live 结算，而该路径指向已封存的选择器 API。现在保持原公开参数并增加可选计划、返回保存成功的 bool；选题、预放猫、Elo 模拟事实与进度同次提交，失败停止，同计划去重。模拟器缓存重试保留原题身份与冻结策略，成功清除失败缓存。真实两入口专项 39 项通过，模拟器仍保留其去重／概率胜负用途，不凭空制造 Elo 绩效数据。
15. **音频退出残留**：最终集成的题库测试虽为 91 项零失败，退出时仍持有正在播放的 `board_enter_1.ogg` 及相关 Ogg 播放资源，因此被严格门禁拒绝。SoundManager 现在在 `_exit_tree` 停止播放器并清空 stream 引用，不发送新事件或写存档。带修复的隔离副本中，题库合同 91 项、音频生命周期 13 项、完整操作 115 项均严格通过；修复已进入最终完整验收版本。
16. **发布负向门禁不完整**：预期拒绝的内容发布案例也会因 SCRIPT／Parse 错误、未预期引擎诊断或退出泄漏而失败；必须同时满足拒绝理由和产物约束，不能只看到非零返回值就算通过。原始 stdout／stderr 在可删除测试工程之外保存，并记录相对／绝对路径及 SHA-256。8 项 Python 回归覆盖合法拒绝、混入错误、嵌套运行器与缺失证据。

17. **关闭等待泄漏**：首轮组件回归虽为 74 项零失败，关闭途中直接销毁窗口仍留下父层 `_do_hide` 协程；真实账号和设置页面也可复现，不能只修测试夹具。公共窗口现在提供按展示代次归属的可取消信号／条件等待，刷新和销毁先失效旧代次，再同步取消等待，产品在取消返回后停止后续操作。账号五页、购买成功、补签、设置、语言、陪伴猫奖励、主线胜利与每日三个弹窗共 14 页接入；保留正常关闭的动画与信号语义。Daily 教程父流程另外持有子页的弱引用和展示代次：子页取消或重开时恢复仍有效父页面的计时，新的展示即使立即发出完成信号也不能记为旧教程完成。最终独立公共取消／销毁合同 68 项（原 47 项保留，新增 21 项）、原公共框架 260 项严格通过；组件回归原 74 项全部保留，新增 83 项真实页面关闭／重开／销毁及设置回调断言，共 157 项严格通过，退出无协程或资源泄漏诊断。相关修复已通过最终完整验收。

18. **公共身份与析构合同**：确认弹窗原本覆写公共展示代次，并在正常关闭时增加局部动画计数，造成窗口管理器误判换页、留下隐藏窗口的堆栈占位，最终让销毁等待不结束。确认弹窗现在继承基类展示身份，局部动画计数仅用于自身动画；正常关闭身份、出栈及有界销毁都有断言。`PREDELETE` 统一进入幂等销毁流程，已初始化页面的 `on_destroy` 恰好执行一次，未进入生命周期的场景模板跳过依赖初始化的产品钩子。最终真实弹窗 80 项、每日事务 45 项严格通过；每日页面关闭与教程取消组合回归为 126 项，旧实现负向对照能捕获计时停滞与误记完成。

选题成功后的辅助用户标签刷新与无效推荐诊断也列为明确行为合同：准备阶段只记录效果，正式提交后再发布；写盘失败不得提前触发，恢复及重复计划不能重复发布。这条发布链已通过 49 项专项断言，包含持久辅助标签的首局行为、延迟 SDK 回包、真正的就绪信号、重置、重复提交和公开选题入口。特殊关的策略判断、预览、难度轮换与题源也统一读取同一冻结表，支持显式新增／删除配置；112 个启用策略值的完整矩阵 588 项严格通过。runtime 参数审计覆盖 103 个接口及 1,312 个调用，已修复队首复检和策略内部漏传；明确支持默认值的边界与需要冻结 runtime 的策略调用分开核对，见 [调用审计](migration/1.22-runtime-call-audit.json)。

19. **验证工程的音频退出协议**：仅在验证夹具结束全部页面工作后，捕获音频流与播放对象的弱引用，显式停止并解除播放器持有，再有界等待这些引用实际失效。到期仍持有或等待期间出现新播放器均判失败，不能以停止播放、经过若干帧或退出码为零代替释放证据。该协议有 14 项可重复正负回归；真实题库测试新增释放断言后为 92 项严格通过。原极速退出负例保留，这项改动不重构生产应用的退出流程。见 [退出协议证据](validation/migration-1.22-audio-protocol/index.json)。

## 验收口径

最终验收固定输入后运行 `python3 tools/verify.py --suite all --godot ENGINE`，核对完整子报告与日志。单项检查覆盖的维度包括：资源冷导入与恢复身份、全部策略可解析及 112 个实验值代表性选择、真实页面按钮、故障注入、重复提交、隐藏／销毁／重入、纯业务端口、独立 UI／framework／Block、开发与模拟 release、签名 HTTP 内容、发布拒绝矩阵、Spine 和 PCK。

所有产品测试复制完整工程到临时目录，重定向脚本存档并设置独立原生用户目录，生产传输入口显式失败，编辑器远控和生产同步禁用。最终报告必须对应这份完整副本；早期只刷新脚本的排错副本不作为完整版本验收证据。

## 明确未验证的部分

- 生产 CDN/TLS 与线上内容分发未验收；通过的是隔离回环 HTTP、签名、回退与内容资源合同。
- 没有真实 Android/iOS 设备、商店账号和完整商业 SDK 的端到端验收。桌面替身验证成功／失败／取消／重复／迟到等协议行为，不能证明真实支付或广告可用。
- 原生广告桥如果只回传 placement、不能回传逐次身份，奖励广告仍拒绝发起。恢复可用前必须补全可验证的 show_id 桥并真机测试，不能退回按广告位猜配奖励。
- 调试边界包含模拟 release 谓词测试；这不等于已经导出并安装正式移动包。PCK 验证证明内容资源与 UID 合同，不证明 APK、权限或移动平台性能。
- **已知引擎退出边界**：当前 Godot 4.6.1 定制构建在播放 Ogg 后只运行数帧便退出时，仍可能报告 4 个音频对象与 2 个资源残留。零 Autoload、零公共框架的最小工程可独立复现；同样时序只加载、不播放则通过。正常完整回归与这项极速微型探针分别报告，微型探针仍判失败，不加入豁免。目前没有证据证明会长期累积，也不据此断言具体音频线程机制；本次不修改外部引擎。见 [最小对照证据](validation/migration-1.22-audio-exit/index.json)。
- 原恢复身份报告不保证原包本身无缺陷。自动测试和有限画面检查也不能穷尽全部实验组合、设备和运行时序。
