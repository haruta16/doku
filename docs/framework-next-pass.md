## 2026-10-28 按用户要求恢复原版道具计费

此前将“提示免费复看”和“无目标不消费”一概列为缺陷修复不够准确。本轮以恢复基线 `7af200ca1b582a86c92ab3d498c6af43a20d201a` 的实际产品行为为准，恢复用户指定的收费规则，保留当前事务、失败保护和请求去重。

| 行为 | 原版核对与本次结果 |
| --- | --- |
| 关闭提示后重新打开 | 每次新请求成功都收费并生成新凭证，同盘面也不免费复看；应用当前提示不再次收费 |
| 定位找不到候选 | 按一次使用收费并累计道具使用次数，随后返回；不产生落猫、棋盘变化或步历史 |
| 撤销无可选步骤 | 原版本就不收费，继续保留；空历史、保护格和高亮耗尽不会被一律改成付费失败 |
| 撤销选中了步骤但格值未变 | 原版仍消费并移除所选及更新的历史，本次恢复这一边界；棋盘保护规则不顺带改动 |
| 普通关没有提示方案 | 仍不扣提示，SP关保留定位降级 |
| 免费、库存不足、写失败 | 现有免费策略有效；库存不足沿用广告补充且不自动使用，写失败不扣费、不发布新凭证 |

旧实现证据位于 `scripts/module/game/view/base_game_page.gd`：定位 `_consume_tool()` 在候选查找之前；提示在找到方案后消费；撤销先确认可选步骤再消费。这里恢复计费行为，没有退回“先改活库存、再尝试保存”的旧实现。新序号表示新的主动使用，同序号仅是同笔请求重试，后者不能重复扣费。

定向回归覆盖真实主线和每日提示关闭重开、空定位、广告补充、空撤销、无变化撤销及提交失败。新增收费边界67项、真实游戏用例52项、独立会话36项通过；纯工具与宿主去重回归也通过。最终冻结后的完整隔离验收 **54/54步骤通过**（52个自包含脚本、编辑器导入、600帧启动），独立业务共51项通过。950份输入记录指纹，949份复制输入与通过副本一致，`export_presets.cfg` 仅记录、未导出。4个步骤仍有退出资源告警，数量减少不作为泄漏已经修复的证据。完整验收记录见[本轮报告](validation/original-tool-costs-report.json)。

## 2026-10-27 收尾范围与产品决定

本轮修复现有内容交付、消费与页面生命周期的具体缺陷，不以追平其他项目的功能数量为目标。

## 有意保留的设计边界

普通手势合并检查点，关键消费/奖励即时事务；持续写失败时只能恢复最后成功检查点。
现有 UIManager/GameState 仍保留产品兼容入口，动画和流程仍属于页面；不要求所有代码离开节点。
新增玩法自行实现规则、内容结构和视图，复用已验证的宿主、存档、交付和事务；不承诺只改配置就得到三消。
新核心暂为 schema 1，有真实数据升级需求时再增加明确迁移；不搭建无人使用的迁移平台。

用户排除的云存档、团队、排行榜、服务器反作弊、代码热更和完整运营后台未纳入实现。
没有新增本地业务 HTTP 服务器，没有照搬 TileMatch 模块。
测试不读取或改写日常玩家存档。上述实施轮次当时保留用户已有修改、未创建 Git 提交；成果随后已按用户要求提交为 `d89f94d`。
