## 学习内容的处理

新旧原字节码相同的 43 份脚本保留现有学习源码；其它脚本按函数内容迁移注释，并补充新增模块和关键状态流。变化逻辑的旧注释不因函数同名而强行保留。

旧版 01–06 篇学习笔记注明了版本，内容没有伪装成新版逐行说明。七种抽象和命名笔记继续保留，新增 08 篇提供新版导读。用户原有的 `docs/learning/README.md` 未提交修改和 `07-naming.md` 新文件保留，不混作本次新增内容。

## 可复现材料

- `docs/recovery/1.22.0/package_manifest.json`：直接从原 XAPK 生成的预期清单。
- `runtime_manifest.json`：原题库解码的结构、统计、舍入差异和 API 基线。
- `bytecode_fidelity_report.json`：原始恢复层的同一性证据。
- `atlas_recovery_report.json` / `all_texture_audit_report.json`：图像核验。
- `android_build_report.json`：最终构建产物信息。
- `tools/`：清单校验、格式整理、注释迁移、图集恢复、题库解码和验收工具。

未入库的原包、未加工恢复基线、中间产物及详细日志位于 `originals/upgrades/1.22.0/`。此目录被 Git 与 Godot 扫描排除。它是本机恢复证据，不是项目运行依赖；从仓库重新导入和构建只依赖已入库源码/资源及外部工具链。
