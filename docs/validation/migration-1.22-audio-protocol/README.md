# 1.22 验证音频退出协议

真实题库测试曾完成 91 条断言后仍留下 Ogg 播放资源，严格门禁将其判为失败。纯引擎对照也复现相同极速退出残留；原失败记录保留在相邻 `migration-1.22-audio-exit`，不改为通过。

当前协议仅用于隔离验证夹具的最终清理：页面销毁后，在 SceneTree 仍运行时停止音频并清空播放器的流引用；逐帧观察 AudioStream 与 AudioStreamPlayback 的弱引用实际消失，设 2000 ms 上限。到期仍有引用、播放器恢复播放或等待期间出现新播放器，均返回失败。没有固定 sleep，也没有日志豁免。

`tools/validation/test_audio_shutdown.gd` 自动纳入既有套件，14 条断言覆盖正常释放、故意持有引用的到期拒绝、等待中新增播放器以及负例的正常清理。真实题库改为断言资源已经释放后退出，最终 92 条断言严格通过；观测为 65 个引用、10 次轮询、61 ms，所有引用消失且无恢复播放。

`index.json` 记录五个已应用文件的 SHA、原始日志哈希验证及 ZIP 条目映射。`evidence.zip` 保留纯对照、原型正负例、最终 14 条回归与真实题库 92 条结果的原始报告和日志；包含失败基线，成功案例不能覆盖或替代它。原始报告中的临时路径通过索引映射到 ZIP 内对应条目。
