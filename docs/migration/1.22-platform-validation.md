# 1.22 平台、资源与可见验证边界

本记录对应原始 1.22 提交 `2af1f49bdde26131f85a453a821fce7351cf4885` 向当前框架的迁移。原始恢复证据保留在 `docs/recovery/1.22.0`；迁移后的脚本、场景和运行时适配不能冒充原始字节证据。

## 已验证范围

- 原始 35 个 Autoload 均保留且路径映射正确，新增 `ContentRuntime`。187 个原始场景、相对 `7af200c` 新增的 131 个场景、64 个原始界面注册路径、156 个实验配置变量及 89 个 Addon 脚本均无缺项。
- 853 个原始脚本身份、187 个场景、75 个翻译、59 个题库的恢复校验与原始哈希证据仍成立。两份二进制弹窗动画保持原始语义，迁移版与原件加载后转为文本资源的内容相同。
- 75 份恢复翻译文件不改字节。`LanguageManager` 在运行时代理翻译，只重定位 `[img]` 标签内的旧资产根路径；原文、复数、外链和已经迁移的路径保持原意。引擎退出前移除脚本代理，避免晚于 GDScript 关闭的析构。项目追加注册 62 份框架恢复提示 PO。
- 每日入口覆盖 OFF、同会话、跨会话恢复；无效题池拒绝开局；开局、残局、结算、签到、奖励、复活及重开通过候选事务提交。写失败保持旧数据和可重试入口，异步展示按页面和对局代次取消。
- 广告回归使用真实产品页面和 Mock/测试桥接，验证准确的 `show_id`、历史登记与领取的写失败重试、乱序与重复回调、重入、重置、隐藏和销毁。它不等价于原生广告供应商验收。
- 独立内容工具实际运行回环 HTTP 失败/恢复、签名校验、冷进程恢复、Spine PCK 挂载及导出资源读取。临时密钥与服务器仅用于测试，没有向生产服务发布内容。

## 可见验证

`tools/validation/capture_v122_ui.gd` 只能在隔离副本中、使用真实图形渲染器运行。它通过真实 UIManager 和页面入口生成主页、四道具主线、已开启草稿、每日挑战、新教程、陪伴猫、装扮展示、通用奖励及中文每日画面。

捕获不仅检查文件存在，也检查页面仍可见、画面包含足够颜色；最终截图仍需逐张人工检查。测试以本地候选准备排行资格，避免首期排行教学正常跳入主线后产生被误认为主页的灰屏。

已用 Godot 4.6.1 自定义 Spine 引擎、桌面 OpenGL compatibility、540×1200 窗口完成九张画面复核。画面没有明显截断、缺图、空白、缺失动画轨道或脚本错误。该结果不覆盖移动设备触摸手感、刘海/安全区、所有屏幕比例和所有实验组合。兼容渲染器会将不支持的 BPTC 纹理转换为 RGBA8，这也不代表 Android 压缩纹理性能已验收。

装扮截图是独立展示夹具，没有建立限时权益，因此图上的 `00:00` 不用于验收试用期计时。功能是否发放、何时到期应由对应业务事务测试和设备流程证明。

## 尚未完成的原生验收

- 当前环境缺少所需自定义 Spine Android debug/release 导出模板，未生成和安装迁移后的正式 APK。原始恢复报告中的 APK 证据只属于原始恢复版本，不能用于宣称本次移植已通过 Android 构建或设备验收。
- 已恢复的原生广告接口只有 placement 回调，无法证明回调属于哪一次展示。新的业务边界要求带展示身份的原生桥接；缺少该桥接时真实奖励广告拒绝发奖，防止串奖。Mock 测试通过不解除这个发布前条件。
- 未运行真实广告供应商、购买/订阅、账号认证、云存档同步、推送、ATT、生产 TLS 或远端配置服务。没有读取真实游戏存档，也没有使用测试结果代替服务商与设备验收。
- 仍需在匹配的 Android 模板和设备上验证完整资源导出、Spine 渲染、原生回调身份、音频焦点、前后台生命周期、广告关闭/奖励顺序、网络中断及购买恢复。

因此，现有结果支持本地学习工程和隔离功能验证；不能据此宣称可以直接发布到真实用户环境。
